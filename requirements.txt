# AI-Vuln-Scanner runtime dependencies.
#
# SYSTEM REQUIREMENT (not installable with pip): the `nmap` binary must be on
# PATH. vulnscanner.py drives it with subprocess (module docstring: "call the
# local `nmap` binary via subprocess (most reliable)") and parses its XML
# output with xml.etree.ElementTree. It never imports an nmap Python binding,
# so the old `python3-nmap` entry was unused as well as stale.
#
# The AI providers (OpenAI, Groq, DeepSeek) are called over plain HTTP with
# `requests` (module docstring: "OpenAI (HTTP, no openai SDK dependency)"), so
# no AI SDK belongs in this file. The previous `openai` entry pulled in a
# large SDK the code never imports.
